# Опора — глоссарий

**Статус:** исследовательский проектный вариант для командного ревью. Описанные целевые процессы и показатели не являются результатами внедрения. Новые решения требуют голосования команды; исходные измерения ещё не проведены.

| Термин | Значение в проекте | Что с ним нельзя путать |
|---|---|---|
| Договорённость | Версия ожидаемого результата, критериев, участников и контрольной точки | Не автоматический норматив производительности |
| Контрольная точка | Согласованное время содержательного разбора | Не доля прошедшей эстимации и не «% готовности» |
| Артефакт / материал | Документ, прототип, изменение кода или иной проверяемый результат | Наличие/количество ссылок не означает качество |
| Research / spike | Ограниченное исследование конкретного вопроса | Не обязанность ежедневно выдавать PR |
| Отрицательный результат | Обоснованное опровержение гипотезы или непригодность варианта | Не отсутствие выполненной работы |
| DATA_GAP | Нельзя интерпретировать выполнение из-за неполных/устаревших источников | Не «сотрудник ничего не сделал» |
| Блокер | Явная зависимость/препятствие с действием и владельцем | Не автоматическое освобождение от всех договорённостей |
| Приёмка | Проверка конкретного критерия компетентным человеком | Не общая оценка человека |
| DoR / DoD | Условия готовности к работе / завершения | Не заменяют содержательную экспертизу |
| HITL | Человек имеет полномочие проверить, отказать и изменить решение | Не формальная кнопка согласия |
| Provenance | Происхождение факта: источник, версия и время | Не доказательство истинности факта |
| RBAC | Права по роли, дополненные объектным назначением | Не просто скрытие кнопки в интерфейсе |
| Псевдонимизация | Замена явного идентификатора с возможностью связывания | Не анонимность |
| Агрегат | Сводка по группе/периоду | Малый срез может раскрыть участника |
| Retention | Ограниченный срок хранения с удалением связанных копий | Не бессрочный архив |
| Input hash | Контрольная сумма конкретного входного снимка | Не обезличивание и не проверка правдивости |
| LLM | Модель для проверяемых вспомогательных функций AI-P/AI-S/AI-T; включение каждой зависит от эксперимента | Не эксперт по намерению или кадровый решатель |
| Baseline | Измеренная исходная практика до изменения | Не вымышленный сценарный расчёт |
| M1–M4 | Четыре метрики качества и затрат процесса | Не персональный рейтинг |
| AS-IS / TO-BE | Проверяемая модель текущего / предлагаемого процесса | TO-BE не означает, что решение внедрено |

## Различия в исследовании

| Понятие | Значение |
|---|---|
| Электронный мониторинг активности (EPM) | Технологическое наблюдение и анализ сведений о действиях работника |
| Мониторинг продвижения к цели | Проверка движения к заранее определённому результату; в «Опоре» — материал, критерий, контрольная точка и обратная связь |
| Добавочная польза | Улучшение относительно полноценной существующей практики с учётом затрат обеих сторон |
| Стандартизированный эффект d | Различие в единицах стандартного отклонения; d=0,40 не означает рост на 40% |

Первоисточники: [реестр исследований](01_problem.md#sources).

## Развитие решения

| Понятие | Значение |
|---|---|
| Новое противоречие | Конфликт требований, который проявился вследствие выбранного разрешения предыдущего |
| Профиль достаточного материала | Согласованный для типа задачи критерий, минимальный материал и правило содержательной проверки |
| Мощность ревью | Доступное время компетентных людей для согласованных контрольных точек |
| Смена пути / pivot | Отказ от текущего способа разрешения в пользу другой альтернативы по заранее определённым основаниям |
| Доменный профиль | Настраиваемые виды результатов, сроки и доступ в рамках неизменных правил защиты человека |

## Планирование, применение и интерфейс

| Термин | Значение и граница |
|---|---|
| D1–D5 | Основания разбора конкретного результата: критерий, продвижение, препятствие, прогноз, цель; не рейтинг |
| Контекст планирования | Раздельные основания неопределённости, зависимостей, трудоёмкости и критичности; не единая шкала сложности и не сумма баллов |
| Прогноз | Диапазон при заданных допущениях с автором и версией; не гарантированный срок или автоматическая норма труда |
| Содержательное продвижение | Проверяемое изменение результата или знания относительно прошлой точки; не объём написанного текста |
| Родительская цель | Результат, ради которого выполняются связанные подзадачи; дробление не умножает ценность |
| Целевой запрос | Дополнительное разрешённое содержание для конкретного вопроса; не право собирать всё в резерв |
| Ветка B1–B3 | Будущие конфликты обратной связи, самоэксплуатации и автономии; не утверждённая версия MVP |
| Настройки способа работы | Расписание и доступный интерфейс по выбору пользователя; не диагноз и не скидочный коэффициент результата |
| Legal Operations | Организация процессов, ресурсов, данных, знаний и технологий юридической функции; не синоним юриста по ИИ |
| Применимость процесса | Возможность испытать способ работы вручную; не готовый коннектор или подтверждённый спрос |

AI-P — помощь планированию; AI-S — сводка материала; AI-T — помощь разбору расхождений. L0 — ручной контрольный процесс для измерения добавочной пользы, а не отказ от продуктовой гипотезы ИИ.
